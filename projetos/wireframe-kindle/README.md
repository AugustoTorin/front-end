# 📖 Página Wireframe - Kindle

Projeto desenvolvido para praticar HTML e CSS.

A página apresenta um wireframe simples com tópicos e imagens relacionados ao kindle.

## 📙 Conteúdo Estudado

- Estrutura básica do HTML;
- Criação de listas;
- Manipulação de elementos com CSS;
- Variáveis CSS;
- Organização de layout com sections e main.

## 📁 Estrutura do Projeto

- Pasta `css/style.css`
- Pasta `images/`
- `index.html`

## 💻 Tecnologias Utilizadas

- HTML;
- CSS.
