# 📕 Posicionamento e Manipulação de Imagens com Flex

Projeto desenvolvido para praticar HTML e CSS.

A aplicação apresenta diversas divs, manipuladas e estruturadas com foco no comando flex.

## 📚 Conteúdo Estudado

- Estrutura básica do HTML;
- Manipulação de elementos com CSS, com foco em flex;
- Variáveis CSS;
- Organização de layout com divs;
- Funções em CSS.

## 📁 Estrutura do Projeto

- Pasta `css/style.css`
- Pasta `images/`
- `index.html`

## 🚀 Tecnologias Utilizadas

- HTML.
- CSS;
